# AGENTS.md — 共有の取り決め（正本）

このフォルダ（muse-poc/）は、Muse（Metaのパーソナルエージェント）と Claude Code（ローカル実行のコーディングエージェント）が、GitHub経由で非同期に協働するための検証スペースです。このファイルが全エージェント共通の正本です。

## 役割

- **Muse**：リモート側。タスクを TASKS.md に書く。PRの差分を読んでレビューコメントを返す。マージはしない。
- **Claude Code / Codex**：ローカル側。タスクを実装し、ブランチとPRを作る。マージはしない。
- **深川（人間）**：最終判断者。PRのマージ可否を決める。

## 作業の流れ

1. 実装者は TASKS.md の未着手タスクを1つ選ぶ。
2. ブランチ `task/<タスクID>-<slug>` を切って実装する。
3. テストを実行し、通ることを確認してからPRを main 向けに作る。PR本文には「何をしたか」「テスト結果」を書く。
4. レビューコメントが付いたら、同じブランチへの追加コミットで対応し、対応内容をコメントで返す。
5. マージは深川のみが行う。

## ルール

- 変更範囲は原則 muse-poc/ の中だけ。タスクに明記がある場合を除き、リポジトリの他のファイルに触らない。
- 秘密情報（APIキー、パスワード、トークン類）をコミットしない。
- 1タスク = 1ブランチ = 1PR。
